============================================================
免费新闻接口汇总(可直接使用版)
整理时间:2025-06  |  用途:个人学习研究
============================================================
说明:
  1. 以下均为"打开就能用"的 URL,无需注册、无需 APIKey。
  2. 非官方接口(标注"非官方"的)可能随时失效或被风控,建议
     加缓存、控制请求频率(建议每秒不超过 1 次)。
  3. 需要注册拿 Key 的平台(天行数据/聚合数据等)见文末附录,
     不属"直接可用"范围。

------------------------------------------------------------
一、聚合接口(一个 URL 拿多个源,最省事)
------------------------------------------------------------

    今日头条热榜 https://api-hot.imsyy.top/toutiao
    澎湃热榜    https://api-hot.imsyy.top/thepaper
    36氪热榜    https://api-hot.imsyy.top/36kr
    IT之家热榜  https://api-hot.imsyy.top/ithome
    果壳热门    https://api-hot.imsyy.top/guokr
    虎嗅24小时  https://api-hot.imsyy.top/huxiu

二、各来源直接接口(非官方,需带浏览器 UA 更稳)
------------------------------------------------------------

【微博热搜】
  https://weibo.com/ajax/side/hotSearch
  返回 JSON(部分情况需登录 Cookie,失效时用聚合接口)

【知乎热榜】
  https://www.zhihu.com/api/v3/feed/topstory/hot-lists/total?limit=50&desktop=true
  返回 JSON

【百度热搜】
  https://top.baidu.com/api/board?platform=wise&tab=realtime
  返回 JSON

【今日头条热榜】
  https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc
  返回 JSON

【百度贴吧热议话题】
  https://tieba.baidu.com/hottopic/browse/topicList
  返回 JSON

【新浪滚动新闻】
  https://feed.mix.sina.com.cn/api/roll/get?pageid=153&lid=2516&num=50&page=1
  返回 JSON

【IT之家新闻】
  https://api.ithome.com/json/newslist/news
  返回 JSON(热榜请用上方聚合接口)

四、无官方接口的国际通讯社(用 Google News RSS 变通)
------------------------------------------------------------

【路透社 Reuters】(官方 RSS 已于 2020 年停用)
  https://news.google.com/rss/search?q=site:reuters.com

【法新社 AFP】(无免费官方 RSS)
  https://news.google.com/rss/search?q=site:afp.com
  中文结果可加参数:
  https://news.google.com/rss/search?q=site:afp.com&hl=zh-CN&gl=CN&ceid=CN:zh-Hans

------------------------------------------------------------
五、暂无直接免费接口的源(只能爬取或近似)
------------------------------------------------------------

【西瓜视频】无任何免费公开热榜接口。
  替代:用"抖音热榜"近似(https://api-hot.imsyy.top/douyin)
  或自行抓取 https://www.ixigua.com 热榜页。

【央视新闻 / 人民日报 / 中华网】无稳定直连 JSON 接口,
  统一用 RSSHub 公共实例(见第一部分)。

============================================================
使用建议:
  1. 优先用"聚合接口"和"官方 RSS",最省事。
  2. 非官方直连接口请控制频率并做缓存,别用于生产环境。
  3. 商用请走官方授权(微博开放平台、知乎开放平台等)。
